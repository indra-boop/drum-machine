# Lattice

16-step drum machine. Kick, snare, hats, and percussion are synthesized in the browser. No samples.

## Run

```bash
npm install
npm run dev
```

## Play

- **Play / Space** starts and stops the bar.
- Tap a pad to toggle it and hear the hit. Drag across a row to paint.
- **Tempo**, **Swing**, and **Level** sit under the grid. Swing delays the off-sixteenths.
- **Floor**, **Pocket**, **Break**, and **Clave** load a groove. **Clear** and **Randomize** rewrite the bar.
- Tap a voice name to mute it. The pattern is stored in the browser.
